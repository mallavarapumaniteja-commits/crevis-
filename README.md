# crevis.new
🎬 Crevis AI — Creative Event Marketplace

Discover. Connect. Create Memories.

Crevis AI is a creative marketplace designed to connect customers with talented photographers, videographers, and event editors for special occasions such as weddings, Haldi ceremonies, engagements, birthdays, and housewarming events.

Our goal is to make finding the right creative professional simple, convenient, and personalized.

✨ Features

- 👤 Creator Profiles — Explore photographers and editors, view their portfolios, and discover their creative styles.
- ⭐ Ratings & Reviews — Help customers evaluate creators and make informed decisions.
- 🎨 Style Match — Discover creative professionals based on your preferred photography and editing style.
- 🤖 Event Assistant — Get assistance with planning your event-related creative requirements.
- 💰 Budget Estimator — Explore options that align with your event budget.
- 📸 Portfolio Showcase — Let creators display their previous work and creative expertise.
- 📅 Booking & Communication — Support the process of connecting customers with creators for their events.
- 🔐 Creator Onboarding — Enable creative professionals to build profiles and showcase their services.

🎯 Our Mission

To simplify the process of finding and connecting with creative professionals by bringing event photography, videography, and editing services together in one place.

🚀 Getting Started

Prerequisites

Install the following tools before running the project locally:

- Node.js (LTS)
- npm
- Git

Installation

1. Clone the repository:
   
   git clone YOUR_REPOSITORY_URL

2. Navigate to the project directory:
   
   cd crevis.new

3. Install dependencies:
   
   npm install

4. Configure the required environment variables in a ".env.local" file, based on the variables used by the project.

5. Start the development server:
   
   npm run dev

6. Open the local URL displayed in your terminal, usually:
   
   "http://localhost:3000"

🔒 Environment Variables

Some features may require environment variables for database connections, authentication, or external services.

- Configure the required variables locally in ".env.local".
- Add production environment variables through your deployment platform.
- Never commit passwords, API secrets, or private credentials to GitHub.
